# Reproduce the original FIM aircraft example

Section 4 and Table 2 of Bartocci et al. evaluate fault generation on the Aircraft Elevator Control System (AECS). The model is `Aircraft_fault_injector/sf_aircraft_model/Aircraft.slx` in the authors' repository at commit `a110acf2b718eab4cdf65f938203f60009fa0510`. Its SHA-256 is `33774ba8e9eeda22dbcedb3ad960352552984f402d6e559cacf7474fa0180b9c`. Keep the model and its companion files together. [Paper, p. 1719](https://doi.org/10.1145/3540250.3558932) · [Download the pinned authors' checkout](https://gitlab.com/DrishtiYadav/fimtool/-/archive/a110acf2b718eab4cdf65f938203f60009fa0510/fimtool-a110acf2b718eab4cdf65f938203f60009fa0510.zip)

## Use the installer

1. Install FIM Workbench in MATLAB and enter `FIMWorkbench`.
2. Under **Your Simulink model**, browse to the authors' `Aircraft.slx`. Choose a new working-copy filename, for example `fim_paper_aecs.slx`.
3. Beside **Configuration**, click **Load...** and choose `fim-paper-aecs.json` from the examples folder that opens. Click **Create working copy**. The editor lists 45 slots, all off.
4. Select the first row and enable **On**. Click **Compare off / on** and choose a results folder. In the plot, search for `Direct Link Control Law/Gain` to see the difference. Search for `Plant/Left Elevator` to examine a downstream output. You can edit the offset or the time window, enable multiple rows and run another comparison.

## What was exercised

The profile matches the locations generated by the authors' aircraft configuration. The 37 signal connections were matched by original source block, destination block and port. The eight operators were matched by type and their neighboring connections in the original and generated diagrams. To extract the authors' reference table on R2026a, a local copy of their generator skipped the layout-only exception “Layout has not changed since previous arrangement.” The Workbench runs used the pristine aircraft model. [Authors' configuration files](https://gitlab.com/DrishtiYadav/fimtool/-/tree/a110acf2b718eab4cdf65f938203f60009fa0510/Configuration) · [Workbench profile](../../examples/fim-paper-aecs.json)

| Paper fault | Locations | Profile setting |
|---|---:|---|
| Bias / Offset | 20 | Add 0.125 |
| Negate | 17 | Reverse the sign |
| ASR | 2 | Replace the two-input sum signs with `++` |
| S2P | 1 | Replace sum with product |
| P2S | 3 | Replace product with sum |
| ROR | 2 | Replace the comparison with `~=` |

Each case ran separately to 10 s on MATLAB and Simulink R2026a, Linux, with the model's built-in pilot command. The Workbench test chose the fault values above and the interval from 1 s inclusive to 1.05 s exclusive. It seeded the random generator identically before each simulation. Table 2 reports mutant generation times. The measurements here cover waveform behavior.

| Measurement | Result |
|---|---|
| Pristine AECS vs. generated copy with all faults off | All 361 logged signals matched in time, type, shape and value. Maximum absolute error across 354,345 scalar values was 0. |
| Each of the 45 faults on individually | All 45 completed and changed the local output during the window. Across 47,147 local scalar values, including 240 inside the window, the maximum absolute difference from the independently calculated output was 0. |
| All switches restored to off | All 354,345 values again matched the pristine model. |

For slot 1, the comparison export showed a change of 0.000040625 at the downstream `Direct Link Control Law/Gain` output on five samples. The four logged left and right elevator output channels had identical traces in this run. The CSV for each site records its largest **local** change. ## Repeat the checks

Extract the authors' checkout. In MATLAB, supply its top-level folder and choose a new output folder for each command.

~~~matlab
tool = fileparts(which('FIMWorkbench'));
addpath(fullfile(tool,'benchmarks'))
authors = '/path/to/extracted/fimtool';
results = verify_fim_paper(authors,fullfile(pwd,'AECS_run'));
~~~

The run creates an editable `fim_paper_aecs.slx`, a native reference dataset, per-slot measurements, and a `comparison` folder with all-off and slot-1 traces. It compares each fault-stage output with the expected operation on that stage's observed inputs, at the stage's native sample times.

The authors also distribute an Automatic Transmission Controller System (ATCS) example. Run `verify_fim_atcs(authors,fullfile(pwd,'ATCS_run'))` to exercise its four published outputs. Its model workspace requests `sldemo_autotrans_data.mat`, so the check copies the authors' `autotrans_data.mat` unchanged under that name in the run folder. A one-unit offset at the speed output from 7 s inclusive to 10 s exclusive matched the prediction across all 3,004 scalar values.
